# Catatan Belajar: PyJS Path

Catatan belajar Python dan JavaScript. Ada dua jenis file:
- **`YYYY-MM-DD.md`**: rekap harian (ringkasan, kesalahan, jadwal ulang, jurnal).
- **`sesi-XX-*.md`**: catatan per sesi/pelajaran (konsep, latihan, uji diri).

Cara pakai harian: salin `TEMPLATE.md`, ganti nama jadi tanggal, isi, lalu commit.
Contoh pesan commit: `catatan 23 nov: terminal, git, algoritma koin`
