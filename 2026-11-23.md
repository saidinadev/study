## 1. Ringkasan per topik

### g1 Learning How to Learn
- **Active recall:** tutup catatan, ingat dan tulis ulang dari kepala. Membaca ulang hanya membuat terasa familiar.
- **Spaced repetition:** ulangi di hari **1, 3, 7, 21**.
- **Mode fokus vs diffuse:** buntu lebih dari 20 menit, berhenti dulu. Tidur cukup ikut menentukan.

### g2 Terminal
- Perintah: `pwd`, `ls`, `cd`, `cd ..`, `mkdir`, `touch`, `rm` (permanen).
- **Terminal** = menjalankan perintah. **Editor** = menulis isi file. Buka terminal VS Code: `` Ctrl + ` ``.
- Belum dibahas: path absolut vs relatif, `cat`, pipe dan redirect.

### g3 Git & GitHub
- Alur: Working Directory → `git add` → Staging → `git commit` → Repository.
- Git = alat. GitHub = tempat penyimpanan online.
- Perintah: `init`, `status`, `add`, `commit -m "pesan"`, `log --oneline`, `switch -c`, `merge`, `push`, `pull`.
- GUI (Source Control VS Code) boleh dipakai, hasilnya sama dengan terminal.
- Belum dibahas: `.gitignore`, resolve conflict.

## 2. Hasil kerja hari ini

**Soal koin:** cek apakah koin tersedia cukup untuk total permintaan.

Algoritma: jumlahkan semua permintaan, bandingkan dengan koin tersedia.
- Jika total > koin: tidak cukup, `kurang = total - koin`
- Jika tidak: cukup, `sisa = koin - total`

Kode Python yang saya jalankan sendiri:

```python
koin_tersedia = 75
permintaan = [5, 10, 20, 45]
total_diminta = 0

for p in permintaan:
    total_diminta = total_diminta + p

if total_diminta > koin_tersedia:
    print("tidak cukup, kurang", total_diminta - koin_tersedia)
else:
    print("cukup, sisa", koin_tersedia - total_diminta)
```

Output: `tidak cukup, kurang 5` (sesuai hasil tracing).

**Python vs JavaScript:**

| | Python | JavaScript |
|---|---|---|
| Blok kode | indentasi dan `:` | `{ }` |
| Cetak | `print` | `console.log` |
| Variabel | langsung `x = 5` | `const` / `let` |
